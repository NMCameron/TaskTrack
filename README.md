# TaskTrack

TaskTrack is a command-line task manager created for CPS 310.

It allows you to enter and keep track of your personal tasks.

## Current Features

-Add numerous custom tasks.
-View your tasks in order.

## Running the Program

Run on Windows in the terminal by typing:
python tasktrack.py

## Current Limitation

Tasks only exist when the program is open. Once the program is closed all tasks disappear.
