# TaskTrack
TaskTrack is a command-line task manager created for CPS 310.  
It allows you to enter and keep track of your personal tasks.

## Current Features
-Add numerous custom validated tasks.  
-View your tasks in order.  
-Persistent task storage.  

## Requirements
-Python 3

## Project Files
-`tasktrack.py` - Contains the functionality of the command-line task manager  
-`tasks.txt` - Stores/saves any task you add  
-`.gitignore` - Prevents sensitive information from being pushed to GitHub  

## Running the Program
Run on Windows in the terminal by typing:  
python tasktrack.py

## Task Persistence
Tasks are loaded on program launch, and saved immediately after they are added.

## Sample Interaction
Run the program using python tasktrack.py  
Check your tasks by selecting "view tasks"  
Add a task by selecting "Add task" when prompted  
Exit the program once you are done  

## Current Limitation
Tasks can only be added to the list and not removed.
